<h1> start of instructions </h1>
 1) <h4> When you first open the program, you will left-click the run button. ( the button should be green)
 </h4>

 2) <h4> After clicking the run button, you should now left-click. (This is so you can start interacting with the program) </h4>


3) <h4> Now that you have clicked the program, you can type any number with or without a decimal point
   into the program. After typing in a number, you can hit the enter button or the return button (on Mac)
   on your keyboard. </h4>

4) <h4>  After you have clicked the enter button, you will put in a new number for the points needed for an "A"( you will do this step 3 more times for "B", "C", and "D" ) 

5) <h4> After entering the points needed for each letter grade, you will now enter any number with or without a decimal point, for your assignment grade. Once you put in the assignment grade, you will then be asked to enter the name of the assignment (this step will repeat until you enter a negative number into the assignment grade  </h4>

6) <h4> Once you have enter a negative number the progam will use all of the information that you have entered into the program and will result show your total point earn than the percentage of the total and will give you a final letter grade</h4>

7) <h4> Please note that entering letters or text where a number is expected, which will cause the program to not work correctly. Another common mistake is forgetting that the sentinel value must be a negative number to end assignment input. </h4>

  </h4>
